What plays

The splash above is the animation. Every time it loops, or the app starts, it picks a new order from the eight balls, so the ball that is bowled, tapped around the arena and finally dropped in the middle is different each time. The timing never changes. Only the ball does.

The mark in every colour mode

Same shapes, different ink. Use the dark and light versions in the app, the lime badge for the app icon on stores, and the one-colour versions when only one colour is allowed.

App icon, store and phone

Phones do not animate icons, so every icon uses the football. Android also needs a version with only the shapes (themed icon) and a white one for notifications.

Browser tab, share card and email

The tab icon drops the ring and racket holes below 24px so it stays readable.

Loading

The ball laps the arena ring with a lime runner behind it. Each lap is 1.4 seconds and every lap is a different ball, in a random order each time the loader appears.

Two small moments

Booking confirmed uses the landing from the splash, once. Offline and no-connection screens use the same mark with a broken ring and a grey ball, so it still feels like the same app.

Booking confirmedPlays once when the confirmation screen opens. About 1.1 seconds. Still under reduce motion.
No connectionStatic with a slow drift. Replaces the plain wifi icon on full-screen error screens.
